# Лекція 5

У цій лекції реалізовано просту мовну модель на основі нейронної мережі Bengio для роботи з українським текстом.

## Що було зроблено

- Підготовлено навчальний текст `../train.txt`.
- Виконано BPE-токенізацію тексту. Результат збережено у `../train.bpe.txt`, а правила злиття токенів — у `bpe.codes`.
- Створено клас `Vocabulary`, який:
  - будує словник токенів та їхніх індексів;
  - перетворює токени на числові ідентифікатори;
  - зберігає словник у `../vocab.txt`;
  - завантажує словник із файлу.
- Реалізовано підготовку навчальних прикладів із контекстом фіксованого розміру.
- Реалізовано модель Bengio із:
  - embedding-шаром;
  - повнозв'язним шаром;
  - функцією активації `tanh`;
  - вихідним шаром для обчислення розподілу ймовірностей наступного токена.
- Навчено модель на підготовлених прикладах за допомогою SGD та negative log-likelihood loss.
- Збережено навчену модель у `../model.pt`.
- Реалізовано обчислення log-ймовірності тексту та його ймовірності.
- Додано обчислення perplexity для оцінювання мовної моделі.
- Додано валідаційні приклади:
  - речення з навчальної вибірки;
  - нові речення зі схожою структурою;
  - менш природні послідовності токенів.

## Важливі особливості

Токени BPE мають вигляд `кухн@@`, `л@@`, `ом`. Позначка `@@` означає, що токен є частиною слова, а не окремим завершеним словом.

Словник є регістрозалежним: `Кіт` і `кіт` — різні токени. Текст для перевірки має містити саме ті токени, які є у `../vocab.txt`.

Файли з українським текстом і словником потрібно читати та записувати в кодуванні UTF-8.
